## My Major Projects

### 1. Optimization Projects

* **[AIC Planner](https://github.com/diaarca/aic-planner)**  
  Mixed-Integer Linear Programming (MILP) optimization tool built with Google OR-Tools in C++ to compute optimal facility layouts, production flows, and resource consumption.
* **[Baby Tetris](https://github.com/diaarca/baby-tetris)**  
  Markov Decision Process (MDP) model and solver in C++ designed to compute optimal policy strategies for Tetris under stochastic piece arrivals.
* **[Ghost Hunter Simulator](https://github.com/diaarca/ghost-hunter)**  
  Graph theory-based simulation and solver engine in Java modeling the Ghost Hunter board game.

### 2. Other Projects

* **[Dotfiles](https://github.com/diaarca/dotfiles)**  
  Declarative, reproducible workstation environment for Linux and macOS (Apple Silicon) managed with Chezmoi, Nix / Home-Manager, and Neovim (Lua).
* **[NonOS](https://github.com/diaarca/NonOS)**  
  Operating system implemented from scratch (based on NachOS) in C++, including virtual memory, system calls, thread/process scheduling, a file system, and network primitives.
* **[Kube](https://github.com/diaarca/Kube)**  
  Object-oriented Java implementation of the K3 board game featuring automated agents and a graphical user interface.
* **[ARM-Simulator](https://github.com/diaarca/ARM-simulator)**  
  Instruction set architecture emulator in C for a subset of the ARMv5 specification, executing machine code binaries on host systems with different architectures.

### 3. Academic Portfolio

* **[University Projects](https://github.com/diaarca/university-projects)**  
  Centralized showcase repository cataloging university engineering projects across distributed systems, custom memory allocators (`malloc`/`free` in C), Unix shells, network protocols, and databases.

## Recent Pull Requests

* **[fontanf/shopschedulingsolver#11](https://github.com/fontanf/shopschedulingsolver/pull/11)** — *Improved PFSS tree searches and integrated blocking constraint*  
  Enhanced tree search algorithms for the Permutation Flow Shop Scheduling (PFSS) problem and implemented support for blocking constraints (zero-buffer between machines) along with dedicated lower and upper bound evaluations.
* **[fontanf/shopschedulingsolver#17](https://github.com/fontanf/shopschedulingsolver/pull/17)** — *Integrated OR-Tools solver for JSSP*  
  Integrated Google OR-Tools CP-SAT solver for the Job Shop Scheduling Problem (JSSP), incorporating search callbacks for progressive bound/solution reporting, early termination, and constraint pruning.
