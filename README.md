## Selected Projects

### Operations Research & Decision Support

- **[aic-planner](https://github.com/diaarca/aic-planner)**  
  Mixed-Integer Linear Programming (MILP) solver implemented in C++ with Google OR-Tools to optimize production schedules, manufacturing flow networks, and facility resource utilization.
- **[ShopSchedulingSolver](https://github.com/diaarca/shopschedulingsolver)**  
  C++ and Python research framework dedicated to flow shop, job shop, and open shop scheduling benchmarks using exact and heuristic methods.
- **[baby-tetris](https://github.com/diaarca/baby-tetris)**  
  Markov Decision Process (MDP) solver in C++ designed to compute optimal policy strategies under stochastic piece generation through high-performance state-space exploration.
- **Waste Collection Route Optimization (Serre-Ponçon)**  
  Vehicle Routing Problem (VRP) model and decision-support tool implemented in Python for municipal waste management, resulting in a 60-fold reduction in annual travel distance.

### Systems & Architecture

- **[NonOS](https://github.com/diaarca/NonOS)**  
  Operating system implementation from scratch (based on NachOS) in C++, covering virtual memory management, system calls, process/thread scheduling, a file system, and network protocols.
- **[ARM-simulator](https://github.com/diaarca/ARM-simulator)**  
  Instruction set architecture emulator in C for the ARMv5 specification, executing machine code binaries on host systems with different architectures.
- **[dotfiles](https://github.com/diaarca/dotfiles)**  
  Declarative, reproducible development environment tailored for Linux and macOS (Apple Silicon), managed through Chezmoi, Nix / Home-Manager, and Neovim (Lua).

### Academic Portfolio

- **[university-projects](https://github.com/diaarca/university-projects)**  
  Curated index of academic software projects developed throughout university curricula, spanning graph algorithms, operating systems, distributed systems, and language interpreters:
  - **[Ghost Hunter Simulator](https://github.com/diaarca/ghost-hunter)**: Graph-theoretic game simulation engine in Java.
  - **[Kube](https://github.com/diaarca/Kube)**: Complete Java implementation of the K3 board game featuring automated agents and graphical interface.
  - **[MyAlloc](https://github.com/diaarca/MyAlloc)**: Dynamic memory allocator implementing custom `malloc` and `free` primitives in C with pointer arithmetic.
  - **[Mini Shell](https://github.com/diaarca/mini-shell)** & **[FTP](https://github.com/diaarca/FTP)**: Unix command interpreter and client/server file transfer protocol in C.
  - **[Distributed System Game](https://github.com/diaarca/distributed-system-game)**: Multi-node server architecture handling concurrent client workloads in Java.
